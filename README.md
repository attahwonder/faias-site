# FAIAS site

An interactive reading of FAIAS, the Financial AI Independent Assurance Standard, version 1.3.2.

- Site: https://attahwonder.github.io/faias-site/
- Standard: https://github.com/attahwonder/faias-standard

A rendering of FAIAS v1.3.2. The signed text is in the repository: https://github.com/attahwonder/faias-standard

FAIAS v1.3.2 © 2026 Wonder Attah, licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). The text of the standard on this site is quoted from the published repository without change. The files in `data/` are generated from that repository; they are not edited by hand.

Notes that a reader keeps on the site stay in that reader's browser. The site does not send them anywhere.
